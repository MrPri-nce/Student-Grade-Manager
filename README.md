# Student Grade Manager

This project has an upgraded version of my lab02 and was built using pyqt6.

## Features

- Add student names and scores
- Validate user input
- Prevent invalid score entries
- Prevent numbers in the student name field
- Calculate letter grades based on the best score
- Display the best score and average score
- Save and load student data using csv file

## Files
- main.py starts the app
- gui.py takes care of the GUI
- gui.ui contains the pyqt designer interface
- logic.py has the grading logic
- models.py contains the student class
- files handler.py takes care of saving and loading csv data
